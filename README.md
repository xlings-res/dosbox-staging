# dosbox-staging

DOSBox Staging (github.com/dosbox-staging/dosbox-staging) as its project releases it for Linux x86_64, macOS (universal) and Windows x86_64, each with CWSDPMI r7 (DJGPP v2misc), the DPMI host a DJGPP program needs, and `dirun.toml`, the dirun profile that runs a DOS program by it. Built by `tools/res/build.sh dosbox-staging <version>` in openxlings/xim-pkgindex; the recipe is `pkgs/d/dosbox-staging.lua` there.
